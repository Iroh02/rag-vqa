Project Overview

📚

Problem

Standard VQA models answer using only the query image. When questions are ambiguous or answers require disambiguation (e.g., “tennis” vs “badminton”), a single image may not provide enough signal.

💡

Approach

We augment BLIP-2 with a retrieval pipeline: find visually similar images from a knowledge base, inject their Q&A pairs as few-shot hints, and let the model leverage this visual exemplar context for disambiguation and answer formatting.

🏆

Result

RAG boosts VQA accuracy from 42.33% to 51.33% (+9pp) on our evaluation set, with the best configuration using pure image-similarity retrieval (α=1.0).

Tech Stack

BLIP-2 (OPT-2.7B) 4-bit QLoRA CLIP ViT-B/32 FAISS VQAv2 PyTorch HuggingFace

Evaluation Metric

We use the official VQAv2 soft accuracy:

accuracy = min(1, matching_answers / 3)

Each question has 10 human answers. We count how many match our prediction (after normalizing lowercase, removing articles & punctuation). Dividing by 3 means an answer agreed upon by ≥3 annotators gets full credit. This rewards common answers without requiring unanimous agreement.

Knowledge Base

5,000 VQAv2 validation samples used as retrieval corpus (disjoint from eval). Dual FAISS indices for image and text embeddings (512-d, L2-normalized, cosine via inner product).

Retrieval

Search top-30 candidates in each index, take union, re-rank by fused score, return top-3. All on CPU.

Disjoint Splits

KB: val[0:5000], Eval: val[5000:5100], Fine-tune: val[5100:8100]. Zero data leakage.

Key Findings

  • Image similarity dominates: α=1.0 (image-only retrieval) achieves the best accuracy. Text-based retrieval (α=0.0) actually hurts performance, suggesting question text similarity is a poor proxy for answer relevance.
  • RAG consistently helps: All image-weighted configs outperform baseline, with the best showing a +9pp improvement.
  • Gating trades recall for precision: Higher τ reduces RAG usage and slightly lowers peak accuracy, but may improve robustness on out-of-distribution queries.

Error Analysis

Deep dive into 46 incorrect predictions from best config (α=1.0, τ=0.0)

63%

Model Ignored Context

BLIP-2 received relevant hints but generated an answer unrelated to the retrieved context. The pre-trained model wasn't trained to attend to few-shot Q&A context.

29 / 46 errors

20%

Wrong Images Retrieved

CLIP retrieved visually dissimilar images whose Q&A pairs were irrelevant. Retrieval quality bottleneck.

9 / 46 errors

17%

Misleading Answers

Retrieved images were visually similar but had misleading Q&A pairs that steered the model toward incorrect answers.

8 / 46 errors

Implication

The dominant failure mode (63%) is the model ignoring context, not retrieval quality. This motivates QLoRA fine-tuning to teach BLIP-2 to attend to RAG hints.

QLoRA Fine-Tuning

Teaching BLIP-2 to follow RAG context via Hints-style prompt training

Training Setup

  • Adapter: LoRA (r=16, α=32)
  • Target: q_proj, v_proj in OPT-2.7B
  • Trainable: 5.2M / 3.75B (0.14%)
  • Quantization: NF4 (4-bit)
  • Batch: 2 × 8 grad_accum = 16 effective
  • LR: 1e-4, AdamW
  • Data: 3,000 samples (val[5100:8100])
  • No-hints ratio: 15% (baseline preservation)

Hints Prompt Format

Answer with 1-3 words. Hints may be wrong.
Hints:
- Similar image suggests: tennis
- Similar image suggests: racket
- Similar image suggests: outdoor
Question: What sport is being played?
Answer:

15% of training samples omit hints to preserve baseline capability during gated fallback.

Reproducibility

All commands to reproduce our results from scratch

1

Install dependencies

pip install torch transformers peft bitsandbytes faiss-cpu datasets tqdm Pillow
2

Run baseline inference (100 samples)

python run.py infer --num_samples 100
3

Build RAG knowledge base (5000 images)

python run.py rag-build --num_samples 5000
4

Run RAG inference (best config: α=1.0)

python run.py rag-infer --num_samples 100 --alpha 1.0 --tau 0.0 --candidate_k 30
5

Evaluate predictions

python run.py eval
6

Generate training data & fine-tune

python run.py rag-make-train --num_samples 3000
python run.py rag-finetune --epochs 3
